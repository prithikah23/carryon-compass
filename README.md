# Carryon Compass

I want to build Carry-On Compass, a smart packing and outfit-planning app for complex trips. Travelers create a digital wardrobe with each item's weight, size, color, and category. The app combines destinations, weather, activities, trip length, and airline baggage limits to recommend versatile outfits and a realistic packing list, track remaining weight and space, and reserve room for souvenirs.
